# Nudge

A task management application that connects to Firebase to retrieve and display tasks.

## Overview

Nudge is a simple macOS/iOS application that:
- Connects to Firebase Firestore
- Retrieves tasks from a specific collection
- Displays tasks in a clean, user-friendly interface
- Allows creating, updating, and deleting tasks

## Technical Details

- Built with SwiftUI
- Uses Firebase for backend services
- Implements MVVM architecture
